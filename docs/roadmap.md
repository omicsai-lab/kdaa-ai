# Roadmap

## v0.1 — executable theory scaffold

Status: complete for first public repository release.

- strict multilevel data model;
- deterministic provenance-first pipeline;
- optional provenance-gated LLM mode;
- transparent assessment proxies;
- five-container opportunity catalog;
- local JSON/YAML, CV/PDF, OpenAlex, GitHub, and synthetic inputs;
- conservative exact/source-record-equivalent duplicate control with provenance retention;
- JSON/CSV/Markdown/HTML/GraphML exports;
- CLI, FastAPI, Streamlit interface;
- optional calibration and outcome records;
- synthetic benchmark, deterministic perturbation suite, and tests;
- theory/artifact and publication-scope documentation.

## v0.2 — stronger Paper B evaluation

- generic single-shot LLM profile baseline;
- RAG/agentic baseline;
- expanded ablation and model/source perturbation harness;
- semantic/cross-source duplicate resolution and source-independence estimation;
- identity-resolution confidence and disambiguation workflow;
- contribution attribution from repository commits and author-position metadata;
- benchmark dataset manifest and frozen cases;
- cost, token, latency, and error reporting;
- improved opportunity diversity and explanation.

## v0.3 — public real-world case set

- licensed public researcher/laboratory cases;
- manual identity verification;
- blinded claim-evidence audit;
- domain-adapted ontologies;
- direct ORCID and Crossref connectors;
- source-license registry;
- privacy/redaction pipeline;
- report comparison across source subsets.

## v0.4 — human calibration study platform

- consent and participant workflow;
- reviewer assignment and blinding;
- calibration interview interface;
- correction-time capture;
- inter-rater data structure;
- baseline comparison and randomization;
- export for statistical analysis;
- institution-specific governance controls.

## v0.5 — outcome and value learning

- prospective opportunity selection;
- human-only baseline registration;
- workflow instrumentation;
- realized/captured value measures;
- negative outcome and abandonment records;
- versioned portfolio updating;
- calibration models trained only after governance review.

## Production track — separate from research releases

- authentication and role-based access;
- encryption and key management;
- private connectors and data retention;
- organization tenancy and access boundaries;
- audit logs and incident response;
- policy engine for model/provider use;
- independent security and privacy review;
- deployment-specific legal and institutional approval.
